# HRI Wellness Casebook: วิธีเดโม

## สิ่งที่เพิ่มและสิ่งที่แก้

**Baseline** คือการซ่อมระบบเดิมให้ทำงานครบขั้นตอน ในงานนี้แก้ให้ผู้ดูแลกดอนุมัติแล้ว
ข้อมูลถูกเผยแพร่จริงใน Contributions และ Casebook กดซ้ำไม่สร้างรายการซ้ำ
เมื่อปฏิเสธหรือส่งกลับตรวจ รายการสาธารณะจะถูกซ่อนด้วย

**ฟีเจอร์ใหม่** คือคลังเคสการใช้หุ่นยนต์กับคน เลือกดูตามสถานการณ์ รุ่นหุ่นยนต์
และประเภทหลักฐาน แต่ละเคสอธิบายบริบท ปฏิสัมพันธ์ สิ่งที่ต้นทางรายงาน และข้อจำกัด
พร้อมลิงก์อ้างอิงและพิมพ์เป็น PDF ได้ ผู้ใช้ส่งเคสใหม่ให้ผู้ดูแลตรวจได้

ทั้งหมดอยู่ใน Next.js และฐานข้อมูลของ HumanoidTH ใช้ RobotModel, SubmittedData
และ Contribution เดิม เพิ่มข้อมูลเคสใน wellnessDetails และความสัมพันธ์ submissionId

## เปิดเว็บ

```powershell
pnpm dev:casebook
```

เข้า <http://127.0.0.1:3000/wellness> ชื่อบัญชีผู้ตรวจและรหัสผ่านชั่วคราวจะแสดงใน terminal
คำสั่งนี้สร้างฐานข้อมูลสำหรับเดโมไว้ในเครื่อง แยกจากฐานข้อมูลออนไลน์
ข้อมูลเดโมคงอยู่หลังปิดเว็บ รหัสผ่านผู้ตรวจเปลี่ยนทุกครั้งที่เปิดใหม่
ไม่ต้องใช้คีย์ Gemini หรือ YouTube

## เดโมประมาณ 5 นาที

1. เปิด `/wellness` แสดงเคส Dinsaw และ Mirror ที่สรุปจากรายงานของจุฬาลงกรณ์มหาวิทยาลัย
2. เลือกสถานการณ์ แล้วเปิดเคส ชี้ให้เห็นว่ามีปฏิสัมพันธ์อะไร ผลที่รายงานคืออะไร
   และมีข้อจำกัดอะไร เปิดลิงก์ต้นทางเพื่อให้ตรวจสอบได้
3. กด “พิมพ์ / บันทึก PDF” เพื่อเตรียมเคสใช้ในการคุยออกแบบกิจกรรม
4. เปิด `/profile` สมัครบัญชีผู้ใช้ แล้วไป `/submit-data` ส่งเคสพร้อมข้อมูลครบทุกช่อง
   ใช้แหล่งอ้างอิงจริงและไม่ใช้ URL ซ้ำกับรายการที่มีอยู่
5. แสดงว่าสถานะเป็น QUEUED และคนทั่วไปยังมองไม่เห็นเคสนั้น
6. เปิดอีกหน้าต่าง เข้าบัญชีผู้ตรวจที่ `/admin-login` เลือกรายการในคิว ตรวจข้อมูลและกด Approve
7. กลับหน้าคลังเคสและ Contributions แสดงว่ารายการเผยแพร่แล้ว กด Approve ซ้ำก็ยังมีรายการเดียว
8. ในหน้าผู้ดูแล แก้ข้อมูลแล้วกด “Save changes and return to review” รายการจะกลับ NEEDS_REVIEW
   และซ่อนจากสาธารณะ ต้องกด Approve อีกครั้งจึงเผยแพร่ฉบับแก้ไข
9. กด Reject เพื่อแสดงการถอนเผยแพร่ ผู้ส่งยังติดตามสถานะได้ในบัญชีตนเอง

## ความหมายของข้อมูล

เคสเริ่มต้นเป็นสรุปจากรายงานสถาบัน ไม่ใช่ผลทดลองที่ทีมทำเอง และไม่รับรองผลการรักษา
Mirror เป็นระบบ telepresence ในรายงานเก่า ไม่ได้ยืนยันว่ามีให้ใช้งานอยู่ในปัจจุบัน
ผู้ดูแลตรวจความครบถ้วนและที่มา ก่อนใช้ใน Living Lab ต้องประเมินบริบทและความเหมาะสมเอง
